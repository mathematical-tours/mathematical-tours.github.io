# Auxiliary material

These notes, experiments and source documents are preserved separately from the published book. They are not included by the main book build.

| Directory | Contents |
| --- | --- |
| `auto-diff/` | Earlier automatic-differentiation course notes. |
| `mle/` | Maximum-likelihood notes. |
| `diffusion-models/` | Diffusion-model notes, notebook and illustrations. |
| `optim-ml/` | Earlier optimization and machine-learning course documents. |
| `writing-notes/` | Handwritten planning and course notes. |
| `chapters/` | Inactive drafts and sections, including meshes and transport. |
| `source-material/coding-blocks/` | Original block-coding exposition, already integrated into the Shannon coding chapter. |

Existing PDFs are retained. Shared paths in note drivers have been updated, but these historical documents are not covered by the current book's warning-free build contract. Active chapters and included sections live in `../chapters-tex/`.
