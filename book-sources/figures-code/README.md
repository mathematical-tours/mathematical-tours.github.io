# Reproducible book figures

Each figure's source lives in `chapter-<chapter-title>/<figure-name>/`, matching its asset directory under `../figures/`. Chapter numbers are deliberately absent from folder names. The complete inventory is `../figure-processing/figure-project.json`.

## Regeneration

Use Python 3.12 or later, a full TeX Live installation, and the pinned scientific dependencies:

```sh
python3 -m venv build/figure-runtime
build/figure-runtime/bin/python -m pip install -r figures-code/requirements.txt
make
```

The normal build uses `build/figure-runtime/bin/python` when it exists. Set `FIGURE_PYTHON` to use a different interpreter with these dependencies. Build one chapter's proposals, or one figure, with:

```sh
build/figure-runtime/bin/python scripts/regenerate_figures.py --chapter denoising
build/figure-runtime/bin/python scripts/regenerate_figures.py --id denoising--comp-thresh
```

A figure can also be regenerated by running its `generate.py` from any working directory. TikZ sources are compiled from the repository root; the central builder handles their dependencies and composite layouts. Cached figures are rebuilt when code, shared operators, recorded source data, or the drawing preamble changes.

## Contents of a figure folder

- `generate.py`, or named TikZ `.tex` drawings, specifies the figure.
- `original.tex` assembles its current reading-edition panels; it is only for the comparator.
- `proposed.tex`, when present, assembles the regenerated TikZ panels.
- `context.tex` records the surrounding mathematical exposition at migration time.
- `README.md` describes the construction and how to run it.
- Continued figures share a folder and use `-continued` composite filenames.

The parallel asset folder contains byte-preserved current assets in `original/`, a complete `original.pdf`, and the proposed `proposed.pdf`. Python figures also have a PNG preview, `provenance.json`, and, where useful, numerical arrays or actual encoded image streams. Only reconstructions with manifest state `accepted` are included in the reading editions.

## Numerical conventions

`common.py` contains the palette, plotting conventions, real-data loading, periodic finite differences, exact Fourier filtering, wavelet transforms, thresholding rules, and basic variational solvers. Additional shared modules group the approximation, curvelet, variational, sparse-reconstruction, learning, and optimization experiments. Per-figure scripts select and record their own models, parameters and outputs.

Related comparisons use common observations and seeds. SNR is measured before display clipping. Oracle tuning is explicitly identified. Fourier coefficient-budget comparisons use real orthonormal sine/cosine coordinates. Covariance and Gaussian-matrix scalings match the stated formulas. Stationary wavelet synthesis uses the adjoint of normalized analysis; redundant synthesis optimization is performed in coefficient space. Weighted stationary penalties state their atom-norm weights.

The curvelet reference is an explicitly oversampled periodic Parseval frame with smooth parabolic frequency windows and all pixel translations. It is not the fast wrapping implementation with approximately five coefficients per pixel. Its squared partition, synthesis identity and energy identity are checked.

Input data and provenance are in `../data/figure-inputs/` and the supplied `flower.png` and `bird.wav`. Photographic reconstructions use the flower, except for the explicitly requested mandrill texture/codec examples and the documented 1919 Felix the Cat frame. Cropping, resizing and input hashes are recorded. No new reconstruction uses Lena. Synthetic images, spectra, masks and stochastic observations are identified as simulations.

`wavelet_image` displays signed logarithmically compressed coefficients around mid-gray, with the coarse approximation at its image intensity scale. Colored borders use the actual coefficient slices; tensor products use independent horizontal/vertical dyadic partitions. Colors identify decomposition depth, with red at the finest level. Numerical coefficients are unchanged by these display operations.

## Review and acceptance

All 145 reviewed reconstructions are included in the book and all independent chapters. No comparisons remain pending. The one-page `../figure-processing/figure-comparisons.pdf` records completion; the previous 43-entry audit is archived with its matching book and index under `../figure-processing/archive/2026-09-06-reviewed-figures/`.

`review_state` controls publication independently of the Python/TikZ engine; `comparison_visible` controls the audit. The build generates figures before compiling the book and verifies the historical input hashes. Explicitly rejected candidates remain under `figure-processing/archive/rejected-proposals/` and are excluded from regeneration.
