For the binary formulas below, use labels $y_i \in \Yy = \{-1,1\}$. In logistic classification, the prediction $f(\cdot,\be) \in [0,1]$ is a probability for the positive class rather than a class label. We retain the notation $f$ for this probability predictor.


    
\paragraph{Approximate risk minimization.}

A linear score $\dotp{x}{\be}$ defines the classifier $\sign(\dotp{x}{\be})$, with either class assigned when the score is zero. The empirical 0--1 objective counts classification errors, leading to the minimization problem
\eql{\label{eq-ideal-classif}
	\umin{\be} \sum_{i=1}^n \ell_0(-y_i \dotp{x_i}{\be})
} 
where $\ell_0=1_{[0,+\infty)}$ counts zero margins as errors. Away from ties, misclassification corresponds to $\dotp{x_i}{\be}$ and $y_i$ having different signs, so that in this case $\ell_0(-y_i \dotp{x_i}{\be})=1$ (and 0 otherwise for correct classification).

The loss $\ell_0$ is nonconvex, and solving~\eqref{eq-ideal-classif} globally is NP-hard in general. Convex upper bounds on $\ell_0$ provide tractable surrogate objectives.

Two common surrogates are
\eq{
	\ell(u)=(1+u)_+ 
	\qandq
	\ell(u)=\log(1+\exp(u))/\log(2)
}	
These are, respectively, the nonsmooth hinge loss used in support vector machines and the smooth logistic loss. The $1/\log(2)$ is just a constant which makes $\ell_0 \leq \ell$.
  
AdaBoost uses the exponential loss $\ell(u)=e^u$.
 
Least squares uses $\ell(u)=(1+u)^2$. Its growth for large negative margins makes it a poor pointwise approximation of $\ell_0$, although it can still give useful classifiers.
  
Unregularized hinge-loss minimization is equivalent to a linear program with nonnegative slack variables:
\eq{
	\umin{u \geq 0, \be} \enscond{\sum_i u_i}{y_i\dotp{x_i}{\be}\geq1-u_i\text{ for all }i }.
}	


    
\paragraph{Logistic loss probabilistic interpretation.}

Logistic regression applies a sigmoid to the linear score from Section~\ref{sec-linear-models}. The resulting probability predictor is nonlinear. The predicted probability of class $+1$ is
\eql{\label{eq-two-class-logit-model}
	f(x,\be) \eqdef \th(\dotp{x}{\be})
	\qwhereq
   	\th(s) \eqdef \frac{e^{s}}{1+e^s} = (1+e^{-s})^{-1},
}
which is often called the ``logit'' model.
 
Despite its simplicity, a linear classifier can be effective when the feature dimension $p$ is large.
 
With $s=\dotp{x}{\be}$, the predicted probability of class $-1$ is $1-f(x,\be)=\th(-s)$. The identity $\th(-s)=1-\th(s)$ makes the two probabilities sum to one. It does not require balanced class frequencies; an intercept can account for unequal prior frequencies.

For a nonzero parameter, $\be/\norm{\be}$ determines the normal direction of the separating hyperplane, while $1/\norm{\be}$ controls the width of the probability transition. As $\norm{\be} \rightarrow +\infty$ along a fixed direction, the transition approaches a sharp decision boundary.

The predictor $f(x,\be)$ is also a single-layer perceptron with a logistic (sigmoid) activation; see Chapter~\ref{c-deep-learning}.

For conditionally independent labels $y_i\in\{-1,+1\}$, write $\bar y_i=(y_i+1)/2\in\{0,1\}$, $s_i=\dotp{x_i}{\be}$, and $p_i=\th(s_i)$. The likelihood is
\eq{\PP(\yp=y_i\mid\xp=x_i)=p_i^{\bar y_i}(1-p_i)^{1-\bar y_i}.}
Thus the negative log-likelihood is
\eq{\sum_i\{-\bar y_i\log p_i-(1-\bar y_i)\log(1-p_i)\}
=\sum_i\log(1+\exp(-y_is_i)).}
After division by the sample size, this gives the empirical-risk objective~\eqref{eq-erm-param} with logistic loss:
\eql{\label{eq-logistic-optim}
	\hat\be \in \uargmin{\be \in \RR^p} 
		 E(\be)  = \frac{1}{n} \sum_{i=1}^n \loss(\dotp{x_i}{\be},y_i)  
}
where the logistic loss reads
\eql{\label{eq-logistic-loss}
	 \loss( s,y ) \eqdef \log( 1+\exp(-sy) ). 
}
Problem~\eqref{eq-logistic-optim} is a smooth convex minimization. If $X$ has full column rank, $E$ is strictly convex, so it has at most one minimizer. A finite minimizer need not exist for separable data. A positive quadratic penalty guarantees existence and uniqueness.

\paragraph{Gradient descent method.}

Write the objective as
\eq{
	 E(\be) = \Loss(X \be,y) \qwhereq \Loss(s,y)= \frac{1}{n}  \sum_i \loss(s_i,y_i), 
}
Its gradient is
\eq{
	 \nabla E(\be) = X^* \nabla \Loss(X \be,y)
      \qwhereq
      \nabla\Loss(s,y)=-\frac{y}{n}\odot\th(-y\odot s),
}
where $\odot$ is the pointwise multiplication operator, i.e. \texttt{.*} in Matlab.
 
Once $\be^{(\ell=0)} \in \RR^{p}$ is initialized (for instance at $0_{p}$), one step of gradient descent~\eqref{eq-grad-desc} reads
\eq{
	 \iit{\be} = \it{\be} - \tau_\ell \nabla E(\it{\be}). 
}

\subsection{Multiclass Logistic Classification}
\label{sec-multiclass-logit}

For multiclass logistic classification, introduce one weight vector for each of the
$k$ classes. Collect the vectors $\be = ( \be_\ell )_{\ell=1}^k$ as columns of $\be \in \RR^{p \times k}$.

For an input $x \in \RR^p$, convert the class scores into probabilities
using the softmax model:
\eql{\label{eq-multiclass-logitmap}
	 f(x,\be) = \pa{ \frac{ e^{\dotp{x}{\be_\ell}} }{ \sum_m e^{\dotp{x}{\be_m}} } }_\ell
}
The vector $f(x,\be)\in[0,1]^k$ gives the probabilities that $x$ belongs
to each class, and satisfies $\sum_\ell f(x,\be)_\ell=1$.

Estimate $\be$ by maximizing the log-likelihood
over the training sample:
 \eq{
	 \umax{\be \in \RR^{p \times k}} \frac{1}{n} \sum_{i=1}^n \log( f(x_i,\be)_{y_i} ) 
}
where $y_i
