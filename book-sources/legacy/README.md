# Legacy sources

- `matlab/`: original MATLAB examples and the compatibility build launcher formerly in `chapters-pdf/`.
- `chapters/`: superseded chapter fragments and the earlier perceptron text.
- `tools/`: one-time figure migrations and superseded correction utilities.

These files are retained for reference. Historical migration utilities describe earlier directory layouts and must not be rerun against the current figure manifest. Use the maintained tools in `../tools/` and the figure generators in `../figures-code/` for current work.
