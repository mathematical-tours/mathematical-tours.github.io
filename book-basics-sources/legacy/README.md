# Original editions

`pre-revision-2026-09-08/` contains the 335 original files, unchanged, including
the English and French PDFs, chapter sources, original figures and associated
materials. Mixed historical text encodings are deliberately preserved here.

The original file inventory, sizes and SHA-256 checksums are recorded in
`original-manifest.json`. From the revised source directory, run
`python3 tools/check-legacy.py` to verify the complete snapshot.

This archive is available in the source repository. It is excluded from the
Jekyll website build; the published download URLs lead to the revised editions.
