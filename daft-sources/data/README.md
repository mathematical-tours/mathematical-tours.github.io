# Figure inputs

- `flower.png`: the photograph supplied in the adjacent MFDS repository's
  `data/flower.png`, copied without modification. The DAFT generators convert
  it to grayscale and resize it for reproducible numerical examples.
- `cover-still-life.jpg`: the original DAFT cover photograph, retained from the
  archived edition. It is not a numerical experiment or a regenerated figure.

Synthetic signals and shapes are defined in the corresponding Python sources.
No Lena image is used in the revised edition.
