# Historical DAFT edition

`pre-python-2026-09-08/` preserves every file present before the Python modernization, including the 296-page English PDF, MATLAB and Maple programs, figures, exercise implementations, and original build products. All 856 files were copied and verified byte for byte; hashes are recorded in `manifest.json`.

The English book is adapted and translated from Gabriel Peyré, *L'algèbre discrète de la transformée de Fourier*, Ellipses, 2004, ISBN 9782729818678.
